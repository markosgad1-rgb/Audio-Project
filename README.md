# دليل أكواد المشاريع لتسجيل البصمة 📱🏗️
### Project Codes Directory - Site Attendance Quick Copy

تطبيق ويب خفيف وسريع ومتجاوب تماماً مع شاشات الموبايل مخصص لمشرفي المواقع والمهندسين للوصول الفوري لأكواد المشاريع ونسخها بلمسة واحدة لتسجيل بصمات حضور وانصراف فرق العمل على تطبيقات الهواتف.

---

## ✨ المميزات الرئيسية

- ⚡ **نسخ بلمسة واحدة (One-Touch Copy):** زر سريع ومباشر بجانب كل كود لنسخه للحافظة فوراً، مع إشعار بصري وتأكيد اهتزازي (Haptic Feedback) على الموبايل.
- 🔍 **محرك بحث فوري وذكي:** فلترة لحظية بمجرد كتابة أي حرف بدون الحاجة لزر بحث.
- 🔤 **تطبيع ذكي للنصوص العربية (Smart Arabic Normalization):**
  - تجاهل الفروق بين الهمزات (`أ` / `إ` / `آ` / `ٱ` / `ا`).
  - توحيد التاء المربوطة والهاء (`ة` / `ه`).
  - توحيد الألف المقصورة والياء (`ى` / `ي`).
  - إزالة التشكيل والتنوين والكشيدة وتجاهل الفواصل.
- 💾 **حفظ تلقائي (LocalStorage):** يتم حفظ وتحديث كافة المشاريع تلقائياً في ذاكرة المتصفح.
- 🔄 **النسخ الاحتياطي ونقل البيانات:** تصدير واستيراد المشاريع كملف JSON لنقلها بين الهواتف أو حفظ نسخة احتياطية.
- 📱 **واجهة مستخدم Touch-First:** تدعم اتجاهين (RTL للنصوص العربية، و LTR للأكواد الإنجليزية)، مع فلاتر للمشاريع المثبتة (★) وعداد للمشاريع.

## 🚀 طريقة الرفع على GitHub

لرفع المشروع على حسابك في GitHub، اتبع الخطوات التالية من داخل مجلد المشروع في الـ Terminal:

```bash
# 1. تهيئة مستودع Git محلي
git init

# 2. إضافة كافة الملفات
git add .

# 3. حفظ التغييرات الأولى
git commit -m "Initial commit: Project Codes Directory app"

# 4. تغيير اسم الفرع الرئيسي إلى main
git branch -M main

# 5. ربط المستودع بمستودعك الجديد على GitHub (استبدل الرابط برابط مستودعك)
git remote add origin https://github.com/YOUR_USERNAME/project-codes-directory.git

# 6. رفع الملفات إلى GitHub
git push -u origin main
```

## 🌐 طريقة الرفع والنشر على Vercel

المشروع مُجهّز بملف `vercel.json` جاهز للنشر المباشر دون الحاجة لأي إعدادات معقدة.

### الطريقة الأولى: من خلال موقع Vercel (الأسهل والأسرع)
1. افتح موقع [Vercel](https://vercel.com) وسجّل دخولك بحساب GitHub.
2. اضغط على زر **"Add New..."** ثم اختر **"Project"**.
3. اختر المستودع الخاص بك (`project-codes-directory`) واضغط على **"Import"**.
4. سيتعرف Vercel تلقائياً على إعدادات المشروع بفضل ملف `vercel.json`:
   - **Framework Preset:** `Vite`
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
5. اضغط على **"Deploy"**.
6. في غضون ثوانٍ قليلة، سيصبح موقعك متاحاً أونلاين برابط مجاني مثل: `https://project-codes-directory.vercel.app`.

---

### الطريقة الثانية: من خلال Vercel CLI (عبر الـ Terminal)
إذا كنت تفضل استخدام الـ Command Line:

```bash
# تثبيت أداة Vercel إذا لم تكن مثبتة لديك
npm i -g vercel

# تسجيل الدخول والنشر المباشر
vercel --prod
```
